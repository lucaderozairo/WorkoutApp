Activities tab
Sessions the user has posted to the social feed. Shows title, date, key stats, kudos count.
Health tab
Body metrics (weight, resting HR, HRV, VO₂ max) + sleep summary + injuries. Consolidates what was scattered across Profile and Dashboard.
Nutrition tab
Full nutrition logging screen, identical to the current standalone tab. Moved here so mobile nav slot can be freed up.

Implementation approach

A

Component composition (Recommended)

ProfileScreen renders tab buttons with useState. Each tab imports its existing screen component — Nutrition tab renders <NutritionScreen />, Health tab renders existing metric/injury blocks. No duplication, reuses what already works.

B

Inline all content

Same useState tab pattern as Social screen. All content written directly in ProfileScreen.tsx. Simpler, no component boundaries, but the file gets large. Fine if the Health and Activities sections stay small.

C

Nested routes

/profile/activities, /profile/health, /profile/nutrition. Supports deep linking and browser back button. More setup, overkill unless you need shareable profile tab URLs.
