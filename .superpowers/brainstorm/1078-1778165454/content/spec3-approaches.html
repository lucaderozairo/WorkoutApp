Spec 3 — Activity Planning

Three approaches to the planning flow. Pick one before we design the details.

A

Multi-step wizard (Recommended)

Single entry point in the Workout tab ("Plan a session"). Steps: 1 Choose type → 2 Configure → 3 Schedule → 4 Review. The configuration step adapts based on type — exercise picker for gym, map + pace for cardio. Clean, guided, no cognitive overload.

Guided flow Works for all types More taps to complete
B

Split entry points

Two distinct buttons in the Workout tab: "Plan Gym Session" and "Plan Run / Ride / Swim". Each opens a purpose-built form optimised for that type. Fewer steps, but duplicates the scheduling UI and diverges the UX surface area.

Faster per flow Two code paths to maintain
C

Single scrollable form

One long form with a type selector at the top. Changing the type shows/hides the relevant sections inline. No steps — everything visible at once. Fastest to fill in for experienced users, overwhelming for new ones.

Fewest taps Dense UX Hard to extend
What all approaches share
  • Gym: exercise picker + sets/reps/weight + date/time
  • Run/Cycle/Swim: map route (draw or load saved) + target pace + auto distance markers
  • Saved plan appears in Workout tab history and Schedule screen
  • Distance markers auto-calculate from pace (e.g. 5:00/km → 1km = 5:00, 2km = 10:00)
