# Shared Utils

Pure helpers used everywhere. No domain knowledge.

## Categories
- `date/` — formatting, parsing, range math, ISO week
- `string/` — slugify, truncate, plural
- `collection/` — chunk, partition, uniqBy
- `math/` — clamp, round, lerp, percentile
- `result/` — Result combinators
- `id/` — UUID, ULID generation
