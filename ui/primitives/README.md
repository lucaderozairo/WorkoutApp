# Primitives

Atomic, unstyled building blocks. The smallest reusable pieces.

- `Box`, `Stack`, `Inline`, `Grid` — layout primitives
- `Text`, `Heading`, `Label` — typography primitives
- `Pressable`, `Touchable` — interaction primitives
- `Icon`, `Image`, `Svg` — media primitives
- `Spinner`, `Skeleton` — loading primitives

Primitives know nothing about features. They take props and render.
