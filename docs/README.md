# Documentation

This folder is organized by purpose so active guidance, implementation plans,
visual references, and historical material stay easy to scan.

## Current Reference

- `architecture/` - architecture decisions and active system guidance.
- `analysis/` - app audits, architecture analysis, and review artifacts.
- `changelogs/` - dated project change notes.
- `design/` - design system docs and screen briefs.
- `product/` - active product roadmap and feature design specs.
- `reference/` - reusable technical references that are not app-specific plans.

## Work Planning

- `implementation/` - current implementation plans and migration notes.
- `superpowers/plans/` - dated execution plans.
- `superpowers/specs/` - dated design specs that feed execution plans.

## Visual Material

- `prototypes/` - active HTML/TSX/JSX prototypes used for design exploration.
- `screenshots/` - current screen captures and overflow reports.

## Historical Material

- `audits/` - focused reviews and critiques that may still inform future work.
- Superseded docs stay beside their current counterparts with explicit status
  notes, rather than in a separate archive folder.
